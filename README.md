# Calculadora de Matrices

Aplicación desarrollada en Python con interfaz gráfica (Tkinter) que permite realizar operaciones matemáticas con matrices, incluyendo operaciones entre matrices, con escalares y cálculos individuales.


## Funcionalidades

### Operaciones entre matrices
- Suma
- Resta
- Multiplicación
- División (A × B⁻¹)

### Operaciones con escalar
- Suma
- Resta
- Multiplicación
- División

### Operaciones individuales
- Determinante
- Matriz inversa
- Transpuesta
- Traza

### Extras
- Generación automática de matrices
- Manejo de errores personalizados
- Historial de operaciones guardado en archivo `.txt`
- Arquitectura organizada por capas (GUI / Lógica / Utils)
